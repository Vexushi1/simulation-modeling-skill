# Bounded scalar Simulink gain calibration

Use operation `calibration.simulink_gain` only for the approved scalar relation `y=k*u`, using current C symbols and one selected calibrated/assumed parameter. Bind explicit finite lower/upper bounds and a feasible initial trial value to a current C source through `numerical_basis: {source_id, selector}`. The selected structured source object contains exact typed `initial`, `lower`, `upper`, `unit` values. Preserve C null or nominal values; the initial guess is trial input rather than a supplied physical constant.

Training and holdout declare B calibration/validation data-use IDs, exact current B/C CSV path/SHA identities, finite positive per-row weights, time/input/output columns and units, and disjoint original half-open row ranges. Each range has at least two rows on the declared uniform positive grid. Fixed-step starts are nonnegative and grid-aligned; the runner uses actual recorded times without invented samples or resampling. Training input must include nonzero excitation. Record actual applicability/identifiability reasons and limits, prior nonnegative weighted RMSE thresholds and a positive feasibility tolerance. `max_condition_number` and objective remain null; constraint selections are empty.

The independently qualified F trial kernel owns an Inport→Gain→Outport model for this invocation, uses serial `lsqnonlin` trust-region-reflective residuals, and actually simulates each trial through SimulationInput. Current A/F qualification plus current same-runtime E `ode4` are necessary. Library loading, an old E success or an installed optimization product is insufficient. Explicit budgets bound iterations/evaluations, the whole process and each simulation; per-simulation timeout is positive and below process timeout.

Residuals are `sqrt(weight)*(simulated-observed)`. Weighted RMSE is `sqrt(sum(weight*error^2)/sum(weight))`. Preserve every objective call with actual trial parameter, output times/values, solver/diagnostics and model restoration; never replace a failed simulation with cached output, a zero residual or an arbitrary penalty. A native error, early stop, nonfinite result or rejected diagnostics stops that study. Holdout is simulated only after candidate selection and cannot tune the result.

This F-only construction/parameter override does not grant D construction permission for an arbitrary unknown model or override E primary parameters. The successful output remains a candidate; final adoption requires new C approval, D/E final evidence and later numerical verification.
