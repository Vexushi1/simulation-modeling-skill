# Phase F API boundaries

This repository owns the reviewed study, parameter and data semantics, operation qualification, budgets, trial ledger and candidate evidence. These MathWorks API references establish API meaning only; they neither qualify installed toolboxes nor activate a Toolkit workflow. Existing D/E upstream pins remain unchanged.

- [iddata](https://www.mathworks.com/help/ident/ref/iddata.html) and [arx](https://www.mathworks.com/help/ident/ref/arx.html): local `identification.arx_111` uses dense real uniformly sampled SISO data with `[na nb nk]=[1 1 1]`, prediction focus, and explicit coefficient mapping to the approved recurrence. Held-out residuals use measured lagged outputs for one-step prediction; they are not free-run simulation or independent physical validation.
- [lsqnonlin](https://www.mathworks.com/help/optim/ug/lsqnonlin.html): local `calibration.simulink_gain` passes the weighted residual vector to bounded trust-region-reflective least squares. Every evaluation runs an owned Inport/Gain/Outport model. [SimulationInput.setVariable](https://www.mathworks.com/help/simulink/slref/simulink.simulationinput.setvariable.html) scopes the scalar gain to that model's workspace. Simulation errors abort the study, with their ledger preserved.
- [fmincon](https://www.mathworks.com/help/optim/ug/fmincon.html): local `optimization.quadratic_sqp` uses serial SQP for the exact approved positive weighted squared objective, finite bounds and linear inequalities. Public algorithm, counters, positive termination, first-order diagnostic, recomputed objective and feasibility are distinct checks. A local optimizer return is no general global-optimum proof.

Other model structures, arbitrary expression execution, System Identification methods, Simulink Design Optimization, global or multiobjective optimization and Toolkit/MCP execution remain outside this qualification. `fitlm`, `lhsdesign` and `normcdf`, when actually needed by a later task, require their explicit A operation evidence; optional Statistics smoke tests are insufficient.
